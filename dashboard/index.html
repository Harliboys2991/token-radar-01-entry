A launch board, not a price feed

Which protocol without a token would be worth the most if it launched one?

Every protocol below records no token yet. The board ranks them by an implied value computed from the snapshot alone — TVL, seven-day growth, time running with no token, and how many chains it runs on — and gives each one a concrete farm plan with costs and times. Implied value is a model, never a promise, and it says nothing about whether or when a token is issued.

How implied value is computed

One function scores every row. No protocol name is special-cased and no row is hand-picked. The four factors multiply:

  • Base. A quarter of TVL: the launch is priced off the value already locked in the protocol.
  • Growth. Seven-day TVL change, clamped to −60%…+120%, weighted one-half: momentum matters, but a single hot week cannot double a launch.
  • Maturity. 0.60 plus up to 0.40 for age, capped at three years: a protocol that has run a long time with no token has had longer to earn one. Unknown age reads as one year.
  • Breadth. +2% per chain, capped at five chains: a protocol live on more chains reaches more users and more liquidity for the same TVL.

Try the model yourself

Move the sliders and the board re-ranks on the same figures. This changes only what you see here; the ranked board above uses the stated defaults.

How to read this board

The watchlist is the floor, never the ceiling: it holds every protocol with at least $50M of TVL and no token on record. The early radar adds the strongest pre-token protocols below that floor, by TVL. A protocol that records no token may still have one its record does not carry — the snapshot is a record, not proof. Wrapped, staked and bridged products of tokens that already trade are left out on purpose: they are not launches waiting to happen. Live-token protocols are set aside with their market caps, because a market price is a fact and an implied value is a model, and the two should never be mixed.
